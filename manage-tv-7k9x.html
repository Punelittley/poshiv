Где взять токен?
1. Перейдите на GitHub в раздел Personal Access Tokens.
2. Нажмите Generate new token (classic).
3. Поставьте галочку repo (или public_repo) и нажмите Generate.
4. Скопируйте полученный ключ и вставьте сюда. Токен сохранится только в вашем браузере!

📷 Как добавить новую работу в портфолио?

  1. Откройте вкладку «Портфолио и работы».
  2. Нажмите кнопку «+ Добавить новую работу».
  3. Выберите категорию (например, «Шторы» или «Римские шторы»).
  4. Введите заголовок и краткое описание (например, адрес ЖК или стиль интерьера).
  5. Перетащите фото с телефона или компьютера и нажмите «Опубликовать работу».
  6. Скрипт автоматически загрузит фото в репозиторий и создаст карточку на страницах portfolio.html и index.html.
  7. Через 30–60 секунд GitHub Pages автоматически пересоберёт сайт, и новая работа появится онлайн!

🔑 Как устроен доступ и безопасность?

  1. Панель управления работает напрямую с официальным GitHub REST API.
  2. Ваш токен сохраняется только в локальной памяти вашего браузера (localStorage) и не передается ни на какие сторонние серверы.
  3. Любое действие (добавление фото, удаление проекта, смена телефона) создает настоящий Git-коммит в ветку main от вашего имени.
